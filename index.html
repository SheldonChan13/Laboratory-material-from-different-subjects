实验室材料三维模型

本仓库收录不同学科实验室使用的材料 / 构件三维模型（Rhino .3dm 格式）。 所有模型均可直接在浏览器中打开：点击条目进入交互式查看器，可用鼠标拖动旋转、滚轮缩放、右键平移， 并可切换前 / 后 / 左 / 右 / 顶 / 底等标准视角。

Interactive 3D preview of laboratory materials stored as Rhino .3dm files. Rotate with the left mouse button, zoom with the wheel, pan with the right button.

使用说明

  • 模型在浏览器端直接解析 .3dm，无需安装 Rhino / 插件，也不做格式转换。
  • 查看器参数：?model=气体探测器.3dm 可直接定位到指定模型；?src=<URL> 可加载任意外部 .3dm 地址。
  • 模型原始单位为毫米，Rhino 的 Z 轴向上坐标在显示时转换为 three.js 的 Y 轴向上。
  • 新增模型：把 .3dm 放入仓库根目录，并在 assets/models.js 中登记一条记录即可。
